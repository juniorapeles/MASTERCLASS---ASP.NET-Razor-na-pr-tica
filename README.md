# 🚀 MASTERCLASS - ASP.NET Razor na Prática

Este projeto foi desenvolvido acompanhando a aula do **Balta.io**, com foco em construção de aplicações web utilizando **ASP.NET Razor Pages**.

---

## 📚 Aula utilizada

🔗 https://www.youtube.com/live/UNMfTGiAR2c

---

## 🧠 O que foi aprendido

Durante essa aula, foram abordados conceitos importantes como:

- ✔ Estrutura de um projeto Razor Pages
- ✔ Separação entre Layout e Páginas
- ✔ Uso de `_Layout.cshtml`, `_ViewStart` e `_ViewImports`
- ✔ Renderização de dados com Razor (`@foreach`, `@model`)
- ✔ Uso de **Partial Views**
- ✔ Organização de CSS e scripts
- ✔ Boas práticas com ASP.NET

---
